## 📖 Overview

**TalentFlow Pro** is a professional, enterprise‑grade job application tracking system built with React. It helps job seekers manage applications, track interviews, and optimize their job search with AI‑powered resume suggestions.

---

## ✨ Features

| Module | Description |
|--------|-------------|
| 🔐 **Authentication** | Secure login with demo accounts (admin/user/manager), corporate email validation |
| 📊 **Dashboard** | Real‑time stats, interactive charts, clickable analytics cards |
| 📋 **Job Tracker** | Kanban board, add/delete/update jobs, status tracking (Wishlist → Applied → Interview → Offer → Rejected) |
| 🤖 **AI Resume Tool** | Tailor your resume based on job descriptions (UI ready for API integration) |
| 👤 **User Profile** | Edit personal info, notification preferences, dark/light mode toggle |
| ❓ **FAQ & Support** | Searchable FAQs, support ticket system |
| 👥 **Team Collaboration** | Role‑based access (Admin / Manager / User) |

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS
- **Animations:** Framer Motion
- **Charts:** Recharts
- **Icons:** Lucide React
- **Storage:** LocalStorage (backend‑ready)
- **Routing:** React Router v6

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Asdhaq0404/talentflow-pro.git

# Navigate into the folder
cd talentflow-pro

# Install dependencies
npm install

# Start the development server
npm run dev
