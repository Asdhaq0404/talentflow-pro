## 📖 Overview

**TalentFlow Pro** is a professional, enterprise‑grade job application tracking system built with React. It helps job seekers manage applications, track interviews, and optimize their job search with AI‑powered resume suggestions (UI ready for API integration).

🔐 **Live demo credentials** (use any below):
- Admin: `admin@company.com` / `admin123`
- User: `john@company.com` / `john123`
- Manager: `sarah@company.com` / `sarah123`

---

## ✨ Features

| Module | Description |
|--------|-------------|
| 🔐 **Authentication** | Secure login with demo accounts, corporate email validation, role‑based access |
| 📊 **Dashboard** | Real‑time stats, interactive charts (area, pie, progress circle), clickable analytics cards |
| 📋 **Job Tracker** | Full Kanban board – add, delete, update status (Wishlist → Applied → Interview → Offer → Rejected) |
| 🤖 **AI Resume Tool** | Tailor your resume based on job descriptions (UI complete, ready for backend API) |
| 👤 **User Profile** | Edit personal info, notification preferences, dark/light mode toggle, security settings |
| ❓ **FAQ & Support** | Searchable FAQs, support ticket system with live chat / email options |
| 👥 **Team Collaboration** | Role‑based access (Admin / Manager / User) with different sidebar menus |
| 📱 **Responsive Design** | Works perfectly on desktop, tablet, and mobile devices |

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS
- **Animations:** Framer Motion
- **Charts:** Recharts
- **Icons:** Lucide React
- **State Management:** React Context API + LocalStorage
- **Routing:** React Router v6
- **Notifications:** React Hot Toast
- **Forms & Validation:** React Hook Form (ready for extension)

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ and npm installed

### Installation

```bash
# Clone the repository
git clone https://github.com/Asdhaq0404/talentflow-pro.git

# Navigate into the folder
cd talentflow-pro

# Install dependencies
npm install

# Start the development server
npm run dev
